# 《退婚后，我闪婚了首富》— 全场景文生图 Prompt 清单

> 方案一「一副场景对一幅图」配套文案。共 **101 张**，按剧情顺序排列。
> 每张图规格：竖版 **9:16**（建议 1024×1820 或 1080×1920），写实电影感。
> 命名规则：`{sceneId}.jpg`，放进 `images/duanju/scenes/`。

---

## 一、全局风格锚点（每次出图都带上这段）

```
写实电影剧照风格，都市豪门题材，中国面孔，
竖版 9:16 构图，浅景深，胶片颗粒感，
冷调为主、局部暖光点缀，低饱和高对比，
电影感打光（主光偏侧上方），暗部保留细节，
不出现任何文字、水印、logo，
人物面部清晰可辨，除指定角色外不出现其他清晰人脸
```

**负面词（统一加在末尾）：**

```
漫画, 插画, 二次元, 3D渲染, 过度磨皮, 塑料感, 畸变, 多手多指,
文字, 水印, logo, 字幕, 模糊, 低清, 过曝, 死黑, 浓妆艳抹
```
